# 晨昏线可视化 · Terminator View

交互式展示地球/中国地图上随日期与时间实时变化的晨昏线（昼夜分界线）。

- **球体视图**：4096×2048 贴图，可自由拖动旋转，按日期与时间实时计算太阳直射点并绘制晨线/昏线。
- **中国地图视图**：34 个省级行政区边界与省会驻地标注、南海诸岛小图、晨侧与昏侧分色（晨线冷青、昏线暖橙）、可拖动平移与 1–3.6× 缩放。
- 悬停识别省份，点击读取坐标、太阳高度角、地方太阳时、昼长与昼夜状态。

在线访问：https://a13923917757-cell.github.io/terminator-view/

单文件实现，无需构建，直接打开 `index.html` 即可。
